# 2026-11-02

- issue #109：タイトル画面の URL の `?server=…` で、マルチプレイのサーバーの欄を埋めるようにした。
  - 値は `encodeURIComponent` したアドレス（`?server=ws%3A%2F%2F192.168.0.10%3A2567`）。`URLSearchParams` で読むので、エンコードしていない `?server=ws://192.168.0.10:2567` でも読める。`ws://` / `wss://` が無ければ `wss://` を補う（配るリンクは https のページから開くことが多く、そこからは `ws://` につなげないため）。
  - パラメータ名は、参加するときの URL（`?mode=multi&server=…`）と同じ `server` にした。`mode` が無いときだけタイトル画面が出るので、ぶつからない。
  - リンクで開いたときは、マルチプレイの画面を開いた状態で始め、入れたアドレスを localStorage にも覚える（ゲームからタイトルに戻ると URL のパラメータは消えるため）。
  - 形のチェックはいままでどおり「ルームを探す」「参加」のときに `Title.server()` で行う。
