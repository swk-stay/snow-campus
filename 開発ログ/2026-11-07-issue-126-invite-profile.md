# 2026-11-07

- issue #126：入室URL（`?mode=multi&server=…&room=…` / `create=…`）を直接開いたとき、名前も見た目も選ばないまま入っていた（名前が空なら「プレイヤーN」、スキンはランダム）。すぐには入らず、タイトル画面の「ルームに参加」でプレイヤー名とスキンを選んでから入るようにした。
  - タイトル画面の「参加」「作って入る」と区別するため、タイトル画面からの遷移は `from=title` を付け、main は読んだらアドレス欄から消す。読み直しやアドレス欄からコピーした URL ではまた「ルームに参加」が出る。
  - 「ルームに参加」ではサーバーの欄とルーム一覧を隠し、GET /rooms でルームの名前・人数・完成棟数を出す。閉じたルーム・満員のルームは参加のボタンを押せなくして「ほかのルームを探す」を出す。「もどる」「ほかのルームを探す」で URL の mode / room / create を消す（残すと「続きから」で遊んだあとの読み直しや「セーブを消してはじめから」でまた開くため）。
  - 確認：ヘッドレス（ローカルのサーバー）で次を見た。初めての端末で create の URL を開くと名前が空・スキン選択つきの画面が出て、名前なしでは入れず、名前とスキンを選ぶと入れること。読み直すと同じ画面が名前入りで出て Enter で入れること。スマホ幅で room の URL を開くとルーム名と人数が出て横スクロールが出ないこと。無いルーム id で「見つかりません」になりボタンが押せず、「ほかのルームを探す」でルーム一覧に移ること。「もどる」でメニューに戻り URL から mode が消えること。タイトル画面のルーム一覧からの参加と観戦の URL は、この画面を挟まずに入ること。`tsc --noEmit` と `npm run lint` が通ること。
