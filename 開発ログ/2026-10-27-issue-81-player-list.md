# 2026-10-27

- issue #81：マルチプレイ中に、誰がルームにいるかの一覧を画面に出した（`src/playerList.ts`）。
  - 名前は `WorldSync.players` で毎 tick 届いているので、サーバー・プロトコルは触っていない。
  - 決めたこと：
    - 押している間だけ見せる方式ではなく、開け閉めの切り替えにした（スマホでもタップで同じ操作にできるため）。
    - 最初は開いた状態にした（あることに気づいてもらうため）。状態は保存しない。
    - 位置はミニマップの下。幅は名前に合わせて広がる（PC 150〜220px、スマホ 104〜180px）。最初はミニマップと同じ幅に固定していたが、スマホで名前が 1 文字しか見えなかったため。神視点（観戦）はミニマップが無いので右上に出す。
    - Tab は `preventDefault` して、ブラウザのフォーカス移動を止める。キーは神視点でも効くよう `PlayerList` 自身が window で受ける（`main.ts` のキー処理は神視点で早期 return するため）。
    - 自分を先頭に置いて「（自分）」を付ける。観戦は一覧に入っていないので、人数にも数えない。
    - 名前は入力された文字列なので `textContent` で入れる。長い名前は省略記号。毎フレーム呼ばれるので、顔ぶれが変わったときだけ DOM を作り直す。
  - 実装はサブエージェント（Sonnet）に任せ、レビューと検証をした。見出しをタップしたあとフォーカスが残り Enter でも開け閉めしてしまうので、タップ後に blur するようにした。
  - 検証：`npx tsc --noEmit -p .`、`npx eslint src`、`npm run build` を通した。サーバーと Vite を立て、ヘッドレス Chromium（PC 幅 1280 とスマホ幅 390）の 2 人で同じルームに入り、両方に 2 人の名前と「（自分）」が出ること、Tab と見出しのタップで開け閉めできること、観戦（神視点）の端末では右上に 2 人だけ出て Tab が効くこと、1 人抜けると一覧から消えることを確かめた。実機（スマホのタップ・セーフエリア）は未確認。
