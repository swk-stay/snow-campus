# 2026-11-02

- issue #98：空を時刻で変わるようにして、太陽の位置から影を落とすようにした。`feature/issue-98-sky` ブランチ。
  - ユーザーの要望：晴れ・朝焼け・夕焼け・トワイライトのようなきれいな空を重視し、雨と曇りは入れない。夕焼けは太陽の角度から影まで作る。一周は 10 分くらいで、タイムアタック（5〜8 分）が一周しかけるくらいで終わるように。雲は快晴と薄い雲のパターンをいくつか（冬なので積乱雲は出さない）。
  - `render/daylight.ts`（時刻・太陽の位置・色・ライト・影）と `render/skyDome.ts`（空のドーム）を足した。雪原と建物のシェーダーは、固定だった太陽の向きと色を、共有の uniform（`lighting`）と three.js の影に置き換えた。`SnowSurface` と `Monolith` の引数から `sunDir` を外した。
  - 雪原は、日なたの平らな面も太陽の色に染まるようにし（太陽が低いほど強く）、太陽のほうを向いたときの照り返しを足した。夕日で日なたが橙、日陰が青になる。
  - 雪原の外の雪面（`MeshBasicMaterial`）の色と、タイトルのベールの色（CSS 変数 `--sky-color`）も空の時刻に合わせる。
  - 検証：ヘッドレスで、昼の全体マップ（校舎の影が北へ落ちる）、夕日・日の入り直後・明け方のトワイライト（グランドレベルで西を向く）、すじ雲とうろこ雲（朝と夕方）を撮って確かめた。lint と build は通る（lint は `.claude/worktrees/` に別の tsconfig があると落ちるので、`--ignore-pattern '.claude/**'` を付けて流した）。
  - 決めたこと：影を作るときの太陽の高さは 7° より下げない。実際の高さだと、日の出・日の入りの前後にキャンパスのほとんどが日陰になったため。
  - ハマったこと：太陽が沈んだら `castShadow` を切る作りにしかけたが、切り替えると全マテリアルのシェーダーが作り直されるのでやめた。Overpass API はボット判定で取れず、OSM を回した向きは確かめられなかった。
- 次にやること：実機（スマホ・会場のモニター）で fps と見た目を確かめる。太陽の方位を現地の写真などで確かめ、ずれていたら `MAP_NORTH_BEARING` の符号を反転する。
