# 2026-11-07

- スキンに友利奈緒（「Charlotte」）を足した。参考は公式サイト（https://charlotte-anime.jp/character/ ）の立ち絵と顔の正面・横の絵。
  - プリキュアと違って制服なので `cureBody` は使わず、`render/avatars/tomoriNao.ts` で体を自前で組んだ。座標（脚・スカート・胴・腕・頭）はプリキュアと同じにして、背丈と雪玉の位置を合わせている。
    - 赤いブレザー（裾と袖口に白い縁）、白いセーラー襟（後ろの四角い垂れと前の V 字）、黄色いリボン、焦げ茶のプリーツスカート（角を立てた円錐）、黒いニーソックスと茶色のブーツ、右手にビデオカメラ。
  - 髪は `cure.ts` の `hairStrands`・`hairCap`・`onHead` を使った。銀髪で、前髪は右寄りの分け目からおでこに沿って左へ流す。横髪は胸まで、後ろ髪は肩の後ろの横へ広げて腰まで（真後ろは雪玉）。左の頭の上で焦げた赤の結び目でくくったサイドテールを、左の後ろ横に垂らす。垂れる髪は `wave()` で x と z を交互に振って波打たせた。
  - 顔は `cure.ts` の `face()` を export し、目の色（`eye`）と口（`smile: false` で閉じた小さい口）を選べるようにした。既定値はプリキュアの描き方のままで、キュアアンサーの顔が変わっていないことを撮って確かめた。色付きの目には瞳（焦げ茶の楕円）を入れる。肌の材質は `skinMaterial()` に出した。
  - `color`（ミニマップとプレイヤー一覧の点）は焦げ茶のスカートの色にした。銀髪は雪の上で見えず、ブレザーの赤は上着の赤とかぶるため。タイトル画面の見本（`swatch`）は銀髪と赤のグラデーション。
