# 2026-10-13（4）

- issue #42：神視点と Editor のカメラ操作を揃えた。以前は神視点が「OrbitControls ＋ WASD でカメラと注視点を一緒に動かす」、Editor が OrbitControls のみ（WASD なし）で、神視点は遠くの注視点のまわりを回るのが不自然だった。
  - 共通の `FlyCamera`（`flyCamera.ts`）を作り、両方を載せ替えた。向きは yaw / pitch（`rotation.order = 'YXZ'`、pitch は ±89°）で持つ。Pointer Lock 中は `movementX/Y` × 感度で見回し、ロックしていないときはドラッグ。
  - Ctrl は「単独で押して離したとき」だけロックを切り替える（Ctrl+Enter の追加や Ctrl+C などでは切り替えない）。入力欄に書いているときは WASD も Shift も効かない。
  - Editor は Ctrl で「選択モード（カーソルでクリック）」と「視点モード（ロックしてクリックで照準の場所を選ぶ）」を切り替える。Esc でロックを外したときは、選択を解除しない。神視点はクリックでもロックする（場所の指定は無いので）。
  - Editor の OrbitControls の右ドラッグ（パン）は無くなった。移動は WASD / E・Q / ホイールで行う。
- 検証：ヘッドレス Chromium で、Editor のクリックでの座標取得・W で前進・ドラッグで見回し・ホイールで前進・Ctrl でロック → もう一度 Ctrl で解除・テキスト欄で Ctrl+Enter してもロックしないこと、神視点の自動回転・クリックでロックして自動回転が OFF になることを確かめた。`npx tsc --noEmit`・`npm run lint`・`npm run build` が通ること。
- 未確認：実機（GPU）でのマウス感度の具合、スマホでのドラッグ・ピンチの操作感。
