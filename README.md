# snow-campus_poc

消えた大学の校舎を、積もった雪で建て直すブラウザゲームのPoC。舞台は神奈川工科大学の中庭まわり（実寸）。

- Stack: TypeScript + Vite + Three.js (+ lil-gui)
- 対応: PC / スマホ縦持ち
- 将来: Colyseus によるルーム制オンライン協力、glTF 3Dモデルへの差し替え

設計・進捗・引き継ぎ情報は [開発ノート.md](./開発ノート.md) を参照。

## 開発

```sh
npm install
npm run dev        # http://localhost:5173
                   # ?view=god で展示用の神視点
```

## 操作

- PC: WASD / 矢印キーで移動、E でショップ、V で視点切替（見下ろし / グランドレベル）、M で全体マップ、Z / X でグランドレベル時のカメラ回転
- スキル（アイテムで習得）: Space ダッシュ / Q ブースト / R 遠投 / F ブリザード（必殺技）。スマホは右下のボタン
- スマホ: 画面のどこでもドラッグで仮想スティック。ミニマップをタップで全体マップ、左下ボタンで視点切替
- 近くの雪は自動で回収、光の柱が立っている建物の枠に入ると自動で投げ込む
- 進行は自動でブラウザに保存される（ショップの「セーブを消して最初から」でリセット）

## Editor（`/editor.html`）

キャンパスの好きな場所に「ここにベンチを置きたい」「この木を消したい」といったリクエストを置いて、Markdown / JSON で書き出すページ。

- クリックした場所（建物・木・地面）の X / Y / Z 座標を取って、自由なテキストを付ける（種類は 置く / 消す / 変える / メモ）
- 建物の中に置きたいときは「断面」で指定した高さより上を消して、床をクリックする。座標は数値でも直せる（空中にも置ける）
- 木をクリックすると、どの 1 本かが分かるように根元の座標も記録する
- 内容はブラウザに自動保存。「Markdown をコピー」で issue にそのまま貼れる
