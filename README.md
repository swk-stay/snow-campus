# snow-campus_poc

消えた大学の校舎を、積もった雪で建て直すブラウザゲームのPoC。舞台は神奈川工科大学のキャンパス全体（実寸・27 棟）。

- Stack: TypeScript + Vite + Three.js (+ lil-gui)
- 対応: PC / スマホ縦持ち
- マルチプレイ: Colyseus のルームで協力プレイ（サーバーは各自で起動する）
- 将来: glTF 3Dモデルへの差し替え

設計・進捗・引き継ぎ情報は [開発ノート.md](./開発ノート.md)、作業ごとの記録は [開発ログ/](./開発ログ/) を参照。バージョンごとの変更点は [パッチノート.md](./パッチノート.md)。

## 開発

```sh
npm install
npm run dev        # http://localhost:5173
npm run server     # マルチプレイのサーバー（ws://<このマシンのアドレス>:2567）
                   # ?view=god で展示用の神視点
```

## マルチプレイ

1. サーバーを起動する：`npm install` してから `npm run server`。起動すると、タイトル画面に入れるアドレス（`ws://localhost:2567` と LAN のアドレス）が出る。ポートは `PORT`、待ち受けるアドレスは `HOST`（既定 `0.0.0.0`）で変えられる
2. タイトル画面の「マルチプレイ」で、プレイヤー名とサーバーのアドレスを入れる
3. 「ルームを探す」で一覧から入るか、ルーム名を入れて「作って入る」

- ルームの進行（建物・ゴールド・アップグレード・アイテム・雪原）はみんなで共有する。全員が抜けてもルームは残るが、サーバーを止めると消える（ファイルへの保存は #75）
- https で配信したページからは `ws://` のサーバーにつなげない（ブラウザが止める）。`npm run dev` のページから入るか、サーバーの前に TLS を終端するプロキシを置いて `wss://` で入る

## 操作

- 開くとタイトル画面（背景はいまのセーブのキャンパスをカメラが巡る）。「続きから／はじめから」「タイムアタック」「マルチプレイ」（サーバーのアドレスとプレイヤー名を入れて、ルームを探して参加するか新しく作る）を選ぶ。`?mode=normal` を付けるとタイトルを飛ばして通常プレイに入る
- PC: WASD / 矢印キーで移動、E でショップ、V で視点切替（見下ろし / グランドレベル）、M で全体マップ、Z / X でグランドレベル時のカメラ回転
- スキル（アイテムで習得）: Space ダッシュ / Q ブースト / R 遠投 / F ブリザード（必殺技）。スマホは右下のボタン
- スマホ: 画面のどこでもドラッグで仮想スティック。ミニマップをタップで全体マップ、左下ボタンで視点切替
- 近くの雪は自動で回収、光の柱が立っている建物の枠に入ると自動で投げ込む
- 進行は自動でブラウザに保存される（ショップの「セーブを消して最初から」でリセット）
- 神視点（`?view=god`）: クリック（または Ctrl）でマウスに視点が付いて FPS 風に見回せる（Esc で解除）。解除中はドラッグで見回す。WASD / 矢印で見ている方向へ移動、E / Q で上下、ホイールで前後（自機は動かない）。右下のボタンで自動回転 ON/OFF（R）・移動速度（Shift、遅い / 普通 / 速い / 最速）・建物の当たり方（C）、スライダーで感度と視野角、チェックで入った建物を透かすか（OFF なら中から室内が見える）
- URL パラメータ: `?view=god` 展示用の神視点 / `?debug` 調整パネル / `?balance` バランス調整ダッシュボード（B で開閉） / `?mode=timeattack` タイムアタック（タイトル画面の「タイムアタック」とショップの「タイムアタックに挑戦」からも入れる。コースはキャンパス全体に広げる前の中庭まわり・守衛所＋7 棟。ゴールした後は、その状態のまま通常モードで続けられる）

## Editor（`/editor.html`）

キャンパスの好きな場所に「ここにベンチを置きたい」「この木を消したい」といったリクエストを置いて、Markdown / JSON で書き出すページ。

- カメラの操作は神視点と同じ（WASD / 矢印・E / Q・ホイール・Shift、感度と視野角のスライダー、入った建物を透かすかのチェック。設定は両方で共有）。透かしている建物はクリックが通り抜ける。Ctrl で 2 つのモードを切り替える
  - 選択モード：ドラッグで見回し、クリックした場所を選ぶ
  - 視点モード：マウスに視点が付いて見回し、クリックで画面中央（照準）の場所を選ぶ。Ctrl か Esc で選択モードに戻る
- クリックした場所（建物・木・地面）の X / Y / Z 座標を取って、自由なテキストを付ける（種類は 置く / 消す / 変える / メモ）
- 建物の中に置きたいときは「断面」で指定した高さより上を消して、床をクリックする。座標は数値でも直せる（空中にも置ける）
- 木をクリックすると、どの 1 本かが分かるように根元の座標も記録する
- 内容はブラウザに自動保存。「Markdown をコピー」で issue にそのまま貼れる
